📊 Monitoring Kegiatan Harian Menggunakan Excel
Deskripsi
Proyek ini berfokus pada pencatatan dan pemantauan kegiatan harian menggunakan Microsoft Excel. Setiap tugas diberi status untuk menunjukkan apakah sudah dilakukan atau belum.

Dataset
Data terdiri dari:
- Nomor tugas
- Daftar kegiatan
- Status (sudah / belum dilakukan)

Tools & Metode
- Microsoft Excel
- Penggunaan simbol checklist (✔ dan ✘)
- Format font Wingdings untuk visualisasi status

Hasil
- Aktivitas harian dapat dipantau dengan mudah
- Status tugas terlihat lebih jelas dan terstruktur
- Membantu meningkatkan konsistensi kegiatan

Tujuan Proyek
- Melatih penggunaan Excel untuk manajemen aktivitas
- Membantu membangun kebiasaan positif
- Mengelola tugas secara sederhana dan efektif

Insight
Excel tidak hanya digunakan untuk analisis data, tetapi juga dapat dimanfaatkan sebagai alat produktivitas untuk memantau kegiatan sehari-hari.

Penutup
Proyek ini merupakan latihan sederhana dalam penggunaan Excel untuk meningkatkan produktivitas dan konsistensi.
